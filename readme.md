## What is Lumen?

Lumen is a B2B SaaS platform that delivers corporate training through a vertical-video feed — think Instagram or TikTok, but for L&D. Built for UAE enterprise clients, it makes onboarding and upskilling actually engaging instead of a checkbox exercise.

## Stack

- **Frontend:** Next.js, hosted on Netlify
- **Database:** PostgreSQL on Azure UAE North

## Features

- Short-form vertical video training feed
- Role-based access across departments and sub-departments
- Admin dashboards for content and learner management

## Status

Pre-launch. Currently in Closed Alpha Testing
